# Changelog

## 1.0.0 — 2026-09-29

- Launched Lura's FastAPI server and Jinja web player at <https://lura-ten.vercel.app>.
- Fixed catalog search parsing for provider responses containing invalid backslash escapes.
- Added search error handling so provider failures return a useful API message instead of a server traceback.
- Added a Flutter Android client configured for the production Lura server.
- Added Docker-based Android and container builds plus GitHub Actions checks.
- Added original SVG branding, orange-red theme, and light/dark mode.
